---
title: 'Install'
description: 'One binary, no runtime. Grab it from Homebrew, the install script, or npm.'
---

import { Cmd, Ok, Term } from '../snippets/terminal.jsx';

<CodeGroup>

```bash Homebrew
brew install emitsignal/tap/emitsignal
```

```bash Shell
curl -fsSL https://github.com/emitsignal/emitsignal/releases/latest/download/install.sh | sh
```

```bash npm
npm i -g @emitsignal/cli
```

</CodeGroup>

Verify the install:

<Term>
    <Cmd>emitsignal --version</Cmd>
    <Ok>emitsignal 1.0.0 (darwin/arm64)</Ok>
</Term>

The short alias `es` is symlinked automatically, so both names are always available.

## What gets installed

A single static binary with no runtime dependencies. The install script places it at
`/usr/local/bin/emitsignal` (and `/usr/local/bin/es`). Nothing else touches your system.

## Updating

<CodeGroup>

```bash Homebrew
brew upgrade emitsignal
```

```bash Shell
curl -fsSL https://github.com/emitsignal/emitsignal/releases/latest/download/install.sh | sh
```

```bash npm
npm update -g @emitsignal/cli
```

</CodeGroup>

<Note>
    If you installed via Homebrew, run `brew upgrade emitsignal`. Installing via the shell script
    again also works, since it's idempotent.
</Note>
