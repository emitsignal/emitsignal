---
title: 'listen'
description: 'Open a live stream of incoming signals over WebSocket. Filter, format, and pipe.'
---

import { Arrow, Caret, Cmd, Cmt, Dot, Ok, Out, Sp, Term } from '../snippets/terminal.jsx';

```
emitsignal listen [topic|expression] [flags]
```

## Flags

<ParamField body="--priority, -p" type="op N">
    Filter by priority. Accepts comparison operators: `>=2`, `<5`, `=4`.
</ParamField>

<ParamField body="--tag, -t" type="list">
    Only stream events carrying any of these tags.
</ParamField>

<ParamField body="--channel, -c" type="glob">
    Restrict to channels matching a glob pattern, e.g. `alerts/*`.
</ParamField>

<ParamField body="--format, -f" type="pretty | json | compact | tsv" default="pretty">
    Output format. See [Output formats](/cli/formats) for details.
</ParamField>

<ParamField body="--since" type="duration">
    Replay history first (e.g. `1h`, `30m`), then go live.
</ParamField>

<ParamField body="--exec, -x" type="command">
    Run a shell command per event. Signal fields are exposed as `$ES_*` environment variables:
    `$ES_TITLE`, `$ES_BODY`, `$ES_PRIORITY`, `$ES_TAGS`, `$ES_TOPIC`.
</ParamField>

<ParamField body="--no-color" type="flag">
    Disable ANSI color. Auto-disabled when stdout is not a TTY.
</ParamField>

**Filter with a full expression:**

<Term title="emitsignal — zsh">
    <Cmd>emitsignal listen 'priority&gt;=4 AND tag:prod AND NOT tag:resolved'</Cmd>
    <Arrow>
        connected · filter priority&gt;=4 AND tag:prod AND NOT tag:resolved
        <Caret />
    </Arrow>
</Term>

**Pipe to jq:**

<Term title="emitsignal — zsh">
    <Cmd>emitsignal listen -f json | jq -r '.title'</Cmd>
    <Out color="#f7f7f8">High memory on api-02</Out>

**Run a command on every matching event:**

<Term title="emitsignal — zsh">

<Tip>
    Color is automatically disabled when stdout is piped (`| jq`, `> file.txt`, etc.),
    so you never need to add `--no-color` explicitly in scripts.
</Tip>
