---
title: 'Channels'
description: 'Named namespaces that group topics and attach routing rules.'
---

Channels are named namespaces that group topics and attach routing rules. They map
to a topic prefix — all topics under `deploy/` belong to the `deploy` channel.

| Method   | Path            | Auth | Description                                    |
| -------- | --------------- | ---- | ---------------------------------------------- |
| `GET`    | `/channels`     | ✅   | List all channels.                             |
| `GET`    | `/channels/:id` | ✅   | Get a channel and its routing rules.           |
| `POST`   | `/channels`     | ✅   | Create a channel.                              |
| `PUT`    | `/channels/:id` | ✅   | Update a channel's settings and routing rules. |
| `DELETE` | `/channels/:id` | ✅   | Delete a channel.                              |

## Channel object

```json
{
    "created_at": "2026-01-15T09:00:00Z",
    "description": "Production deployments",
    "id": "ch_01j9xz3p4q5r6s7t8u9",
    "name": "deploy",
    "routing_rules": [
        { "deliver": ["push", "slack"], "match": "priority:>=4" },
        { "deliver": ["inbox"], "match": "priority:<=3" },
        { "deliver": ["push", "sms", "slack"], "match": "tag:rollback", "priority_override": 5 },
        { "batch": true, "deliver": ["inbox"], "match": "hour:between(0,7)" }
    ],
    "signal_count_30d": 14820,
    "topic_prefix": "deploy/"
}
```
