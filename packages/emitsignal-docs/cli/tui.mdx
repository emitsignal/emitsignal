## Flags

<ParamField body="--filter, -f" type="expression">
    Pre-apply a filter expression. Same grammar as `listen`. Default: show all subscribed channels.
</ParamField>

<ParamField body="--channel, -c" type="glob">
    Focus a specific channel on launch.
</ParamField>
