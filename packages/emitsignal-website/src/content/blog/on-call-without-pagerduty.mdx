You do not need a six-figure incident platform to wake the right person at 3am. For a team of five who pages a few times a month, EmitSignal plus a small schedule file is enough. Here is the whole thing.

## The topic

Everything pages through one topic. Severity rides on priority and tags:

```bash
curl emitsignal.com/alerts/prod \
  -d "api-02 mem > 92%" -d priority=5 -d tag=sev1
```

## The rotation

Who is on call is just a subscription that you rewrite weekly. A tiny cron job points the on-call alias at this week's human:

```bash
# rotate.sh — run by cron every Monday 09:00
ONCALL=$(./whose-turn.sh)        # -> "maya"
emitsignal route set alerts/oncall --to "user:$ONCALL"
```

## Escalation

If the page is not acknowledged in five minutes, widen the blast radius. Rules 2.0 makes this a two-liner:

```text
priority:5 AND NOT acked within 5m  → sms backup + slack #incident
priority:5 AND NOT acked within 15m → call everyone
```

## Acknowledge from anywhere

```bash
# from the terminal
emitsignal ack alerts/prod
# or tap the notification on your phone
```
