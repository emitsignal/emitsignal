import { Caret, Cmd, Out, Term } from '../snippets/terminal.jsx';

Pass `--format` (or `-f`) to `listen` to control how events are rendered.
Color is automatically disabled when stdout isn't a TTY.

## pretty (default)

Human-readable, color-coded by priority. One event per block.

<Term title="emitsignal — zsh">
    <div style={{ display: 'flex', gap: 9 }}>
        <span style={{ color: '#3f3f46' }}>21:52:14</span>
        <span style={{ color: '#f87171' }}>●</span>
        <span style={{ color: '#71717a' }}>alerts/prod</span>
        <span style={{ color: '#f87171' }}>p5</span>
    </div>
    <Out color="#f7f7f8">&nbsp;&nbsp;High memory on api-02</Out>
    <Out>&nbsp;&nbsp;mem.used &gt; 92% for 5m · #sev2</Out>
</Term>

## compact

One line per event. Good for tailing in a tmux pane.

<Term title="emitsignal — zsh">
    <Out color="#f7f7f8">21:52:14 p5 alerts/prod</Out>
    <Out color="#a1a1a6">&nbsp;&nbsp;High memory on api-02 #sev2</Out>
    <div style={{ height: 6 }} />
    <Out color="#f7f7f8">21:52:22 p3 ci/web</Out>
    <Out color="#a1a1a6">&nbsp;&nbsp;Build passed (247 tests)</Out>
</Term>

## json

One JSON object per line (NDJSON). Pipe to `jq`, store to a file, or ingest into a log shipper.

```json
{
    "priority": 5,
    "tags": ["sev2"],
    "title": "High memory on api-02",
    "topic": "alerts/prod",
    "ts": "21:52:14"
}
```

## tsv

Tab-separated: `ts\ttopic\tpriority\ttitle`. Pipe to `awk`, `cut`, or `sort`.

```
21:52:14	alerts/prod	5	High memory on api-02
21:52:22	ci/web	3	Build passed · feat/oauth-pkce
```

## Pipe patterns

<Term title="emitsignal — zsh">
    <Cmd>emitsignal listen -f json | jq -r '.title'</Cmd>
    <Out color="#f7f7f8">High memory on api-02</Out>
    <Out color="#f7f7f8">TypeError spike</Out>
    <Out color="#f7f7f8">Disk pressure · api-03</Out>
    <div style={{ marginTop: 4 }}>
        <span style={{ color: '#4ade80' }}>$</span>
        <Caret />
    </div>
</Term>

<Term title="emitsignal — zsh">
    <Cmd>{"emitsignal listen -f tsv | awk -F'\\t' '{ print $3, $2 }'"}</Cmd>
    <Out color="#f7f7f8">5 alerts/prod</Out>
    <Out color="#f7f7f8">3 ci/web</Out>
</Term>

<Term title="emitsignal — zsh">
    <Cmd>emitsignal listen -f json --no-color &gt;&gt; /var/log/signals.ndjson</Cmd>
</Term>

<Tip>
    When piping, you never need `--no-color` — it's implied automatically. The flag exists only for
    cases where you're writing to a TTY but want plain text anyway.
</Tip>
