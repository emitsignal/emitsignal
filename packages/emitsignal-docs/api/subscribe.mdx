---
title: 'Subscribe'
description: 'Stream signals in real time over Server-Sent Events.'
---

| Method | Path                                     | Auth | Description                                                       |
| ------ | ---------------------------------------- | ---- | ----------------------------------------------------------------- |
| `GET`  | `/subscribe/:topic`                      | ✅   | Open an SSE stream. Delivers signals in real time as published.   |
| `GET`  | `/subscribe?topics=alerts/*,deploy/prod` | ✅   | Subscribe to multiple topics with a comma-separated list or glob. |

```bash
curl -N \
  -H "Authorization: Bearer es_xxx" \
  "https://api.emitsignal.com/subscribe/alerts/prod"

# SSE stream output:
data: {"id":"sig_xxx","topic":"alerts/prod","message":"High memory","priority":5,"timestamp":"2026-05-28T21:52:14Z"}

data: {"id":"sig_yyy","topic":"alerts/prod","message":"TLS cert expiring","priority":5,"timestamp":"2026-05-28T22:05:32Z"}
```

## Query parameters

<ParamField query="priority" type="string">
    Filter expression, e.g. `priority=>=3`.
</ParamField>

<ParamField query="tag" type="string">
    Filter by tag. Repeatable: `tag=deploy&tag=prod`.
</ParamField>

<ParamField query="replay" type="integer">
    Replay the last N signals before streaming live.
</ParamField>

<ParamField query="since" type="string">
    ISO 8601 timestamp. Only stream signals after this time.
</ParamField>

<ParamField query="format" type="string" default="json">
    `json` (default) or `ndjson`.
</ParamField>
