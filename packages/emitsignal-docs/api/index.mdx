The EmitSignal REST API is JSON over HTTPS. There is no SDK to install: curl works,
and every language works.

## Base URL

All requests are made to a single host, versioned by the `v1` prefix at the
account level (currently implicit).

```
https://api.emitsignal.com
```

## Quickstart

<CodeGroup>

```bash No auth — public demo topic
# Publish a signal — no account needed on /welcome
curl -d "hello" https://api.emitsignal.com/welcome
```

```bash Authenticated publish
curl https://api.emitsignal.com/publish/deploy/prod \
  -H "Authorization: Bearer es_xxxxxxxxxxxx" \
  -H "Content-Type: application/json" \
  -d '{"message": "v2.14.3 shipped", "priority": 4}'
```

</CodeGroup>

<Note>
    Prefer the terminal? The [CLI](/cli/index) wraps every endpoint below in a single static binary.
</Note>
